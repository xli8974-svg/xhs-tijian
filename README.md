# xhs-tijian · 小红书全能教练（湾区版）

一个 Claude skill，管完小红书从「账号没流量」到「这条怎么发」的全部问题。面向北美（尤其湾区）的华人创作者、商家、留学生。

## 能做什么

| 你给的东西 | 它做的事 |
|---|---|
| 零散的话 / 活动照片 + 一两句感想 | 口述成稿：写成能直接发的小红书 + 朋友圈版 |
| 主页截图 / 帖子数据截图 | 账号体检：出一张手机体检报告页，每轮只改一件事 |
| 一段准备发的文案 | 发前查：违禁词、导流词、AI 味、tag 碰撞 |
| 「起标题」 | 标题工厂：6 种结构，前 12 字带搜索词 |
| 「不知道发什么」 | 选题雷达：结合北美日历给本周 5 个选题 |
| 对标账号截图 | 拆对标：能抄的 3 件事 + 差异化切口 |
| 「太像 AI」 | 活人感改写：3 个版本 |
| 「用什么工具查」 | 工具箱：零克查词 / 创作中心 / 新红灰豚，Chrome 连着时自己跑 |

## 安装

把 `xhs-tijian/` 整个文件夹放进你的 Claude skills 目录，或在 Claude 里通过「技能」上传 `SKILL.md`。

## 规矩

- 讲人话，结论先行，每轮只改一个变量
- 每次联网查最新规则，但结果写进结论，不甩链接
- 不编用户没说过的细节，缺的用 `[填：…]` 占位
- 体检结果做成手机页面（见 `examples/tijian-report.html`），聊天里只说两句话

## 来源

局部对齐 Local Align 主持人多年实操 + 薯大妈见面会 + 每次联网核对的最新规则。
